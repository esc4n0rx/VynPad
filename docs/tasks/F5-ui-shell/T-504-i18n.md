# T-504 — i18n PT-BR / EN

| Campo | Valor |

## Objetivo
Toda a UI traduzível desde o início, com PT-BR como padrão.

## Escopo
- `i18next` + `react-i18next`; arquivos `src/i18n/pt-BR.json` e `en.json` organizados por namespace (`common`, `onboarding`, `dashboard`, `devices`, `mapping`, `latency`, `settings`, `errors`, `tray`).
- Idioma inicial: configuração salva → idioma do sistema (se EN) → PT-BR.
- Tipagem das chaves (`CustomTypeOptions`), para que uma chave inexistente dê erro de compilação.
- Formatação de números e datas com `Intl` conforme o idioma.
- Textos do menu de bandeja e das notificações nativas também traduzidos (o backend lê o idioma das configurações).
- Script de CI que falha se uma chave existir em um idioma e faltar no outro.

## Critérios de aceite
- [ ] Trocar o idioma nas Configurações atualiza a UI e o tray na hora.
- [ ] Nenhuma string visível hardcoded (lint `i18next/no-literal-string`).

## Fora de escopo
- Idiomas adicionais.
