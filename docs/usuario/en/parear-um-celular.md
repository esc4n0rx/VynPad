# Pair a phone {#parear}

Pairing introduces the phone to the PC once. After that it reconnects by itself.

## With the QR code or the PIN {#qr-ou-pin}

1. Open **Devices** and click **Pair new**.
2. On the phone, open PadGaming and choose **Pair**.
3. Scan the **QR code** on the PC screen. If you prefer, switch to the **PIN** tab and type the six numbers on the phone.
4. Check that the **fingerprint** shown on the phone is the same as on the PC screen. It guarantees you’re talking to the right PC.

The code changes by itself while the window is open and lasts a few minutes. The QR code works only once.

## Phones nearby {#por-perto}

**Devices → Nearby on the network** lists the phones with PadGaming open on the same network. A **new** device has a **Pair** button. If it doesn’t show up within a few seconds, see [The phone can’t find the PC](#o-celular-nao-encontra-o-pc).

## Ask before accepting {#aprovacao}

In **Settings → General**, turn on **Ask before accepting new devices** so a new phone only joins after you allow it. The request appears as a dialog, even with the app in the tray (the window comes to the front).

## Manage devices {#gerenciar}

In **Devices → Paired** each phone has a menu with:

- **Rename**: the name shown on the cards.
- **Set slot**: the controller (P1 to P4) it prefers to take.
- **Set profile**: the mapping it gets when it connects.
- **Revoke**: drops the connection right away and stops it from coming back without pairing again.
- **Forget**: erases its record and history.

The **Connection history** (at the bottom of the screen) lists the latest connections, disconnections and refusals.
